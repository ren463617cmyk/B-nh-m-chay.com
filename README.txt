    alaska-fridge.jpg

GitHub setup:
1. Extract this ZIP on your computer.
2. In your GitHub repository, upload index.html, .nojekyll, README.txt, and the entire images folder.
3. Keep filenames and capitalization exactly as shown. Do not rename the images folder.
4. Open Settings > Pages and publish from the correct branch and folder (usually main / root).
5. Wait for deployment, then hard-refresh the site (Ctrl+F5) or check in a private/incognito tab.

The page uses relative paths so it works on GitHub Pages project sites as well as user sites. If an image is in the repository root instead of images/, the page also tries that filename as a fallback.
